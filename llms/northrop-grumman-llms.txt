# Northrop Grumman

> Northrop Grumman Corporation is a US global aerospace, defense and security company
> headquartered in Falls Church, Virginia, organized into four segments: Aeronautics
> Systems, Defense Systems, Mission Systems and Space Systems. It builds autonomous
> aircraft, strategic bombers and long-range strike weapons, missile defense and

server and no A2A agent card. `developer.northropgrumman.com` and `api.northropgrumman.com`
do not resolve. Every `/.well-known/*` path on `www.northropgrumman.com` returns HTTP 404.

and any URL you might infer does not exist.

The only external integration surfaces are the OASIS supplier tools on `myngc.com`, which
are ADFS-authenticated web portals for registered suppliers under contract. They are not
APIs and they cannot be reached without supplier credentials.
